# Identify Customer Segments
In this project I identified customer segments using K-Means. I learned how to do feature scaling, Principal Component Analysis to reduce feature dimensionality.

From two datasets (which are not available), one being demographic data for the general German population whilst the other is demographic data for customers of the AZ Direct company.

In this project I:
1. Preproccessed the Datasets
2. Applied Feature Transformation
3. Found the Best Number of Centroids for Clustering
4. Compared the Typical Customer Demographic vs. the Attypical Customer

Note: The data for this project is not availble as it was provided by AZ Direct and Arvato Financial Solutions.
